🔒 Sentinel: Fix Cross-Site Scripting (XSS) in MarkdownRenderer

🎯 What: Replaced a custom, regex-based HTML escaper with `isomorphic-dompurify` to securely sanitize HTML strings rendered inside the `MarkdownRenderer` component.
⚠️ Risk: The previous custom regex for HTML escaping (`replace(/</g, "&lt;")`) was brittle and could potentially be bypassed by complex payloads or edge cases, allowing execution of malicious scripts (XSS) in the browser when rendering markdown.
🛡️ Solution: Integrated `isomorphic-dompurify` to sanitize all generated HTML before passing it to `dangerouslySetInnerHTML`. This ensures robust XSS protection out of the box while preserving expected formatting. Added the new security finding to `.jules/sentinel.md`.
